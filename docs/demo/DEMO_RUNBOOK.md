# Three-Minute Demo Runbook

This runbook is for the final English-subtitled submission video. Use only assets marked approved in the [media rights register](MEDIA_RIGHTS_REGISTER.md).

| Time | What the viewer sees | Proof point |
| --- | --- | --- |
| 0:00–0:15 | A phone-sized screen introduces the family problem. The user says or types: “Make a cheerful garden memory from these moments.” | Voice/text request and mobile-first clarity. |
| 0:15–0:35 | The user deliberately selects the consented album and confirms permission. | The browser does not scan the wider phone library. |
| 0:35–0:55 | The user taps **Make my film** and sees a compact preparing state. | One action replaces timeline editing and plan-review screens. |
| 0:55–1:15 | The app shows the approximately-one-minute portrait preview and a short explanation of selected/held-back moments. | Explainable, non-destructive automatic curation. |
| 1:15–1:35 | Show original memory-song generation only if it is working. | Safety/provenance and instrumental/no-sound fallback; never a copied singer or song. |
| 1:35–1:55 | Show the runtime ClickHouse MCP consent/export check and friendly explanation. | Required ClickHouse track proof: official MCP server is used at runtime. |
| 1:55–2:25 | Show the completed vertical MP4, then tap **Save & share**. | Working end-to-end output and real consent/export gate, not a conceptual mock-up. |
| 2:25–2:45 | The user saves the film and chooses their own social platform. | Device-native share/download preserves autonomy; no social-account access. |
| 2:45–3:00 | Closing card: “Memory Director — every memory, directed by you.” | Product name, track acknowledgement, repository and hosted URL. |

## Recording checklist

- Record actual product interactions; do not use slides in place of required runtime evidence.
- Add English subtitles to all spoken material.
- Capture the ClickHouse MCP consent/export tool call and its user-visible explanation in the same recording.
- If the original memory song is included, capture its generation/safety evidence; otherwise use the verified instrumental/no-sound path without claiming the song feature.
- Confirm the public repository, hosted application, and demo-video URL work in an incognito browser before submission.
- Rehearse with seeded preferences and approved fixture media so the story remains repeatable.

# Three-Minute Demo Runbook

This runbook is for the final English-subtitled submission video. Use only assets marked approved in the [media rights register](MEDIA_RIGHTS_REGISTER.md).

| Time | What the viewer sees | Proof point |
| --- | --- | --- |
| 0:00–0:15 | A phone-sized screen. The user says or types: “Make a cheerful travel memory video from these photos.” | Voice-first, mobile-first accessibility; text fallback is visible. |
| 0:15–0:35 | The user selects the consented album and confirms permission to use it. | Consent gate prevents planning without permission. |
| 0:35–0:55 | Gemini proposes a short, clear plan and explains held-back duplicates or low-quality assets. | Agentic media curation is explainable and non-destructive. |
| 0:55–1:15 | The system asks one location-confirmation question and offers three music directions. | No unconfirmed place enters final copy; cultural music direction is user-controlled. |
| 1:15–1:35 | Show the runtime ClickHouse MCP query and the friendly explanation of a prior preference. | Required ClickHouse track proof: official MCP server is used at runtime. |
| 1:35–1:55 | The user approves the storyboard. Attempting a render before approval is visibly blocked; approval permits it. | Explicit render approval and safe control boundary. |
| 1:55–2:25 | The vertical 45–60 second MP4 renders with a cover, title, caption, and high-contrast subtitles. | Working end-to-end output, not a conceptual mock-up. |
| 2:25–2:45 | The user saves the package to the phone and chooses their own social platform. | Manual sharing preserves autonomy; no social-account access is required. |
| 2:45–3:00 | Closing card: “Memory Director — every memory, directed by you.” | Product name, track acknowledgement, repository and hosted URL. |

## Recording checklist

- Record actual product interactions; do not use slides in place of required runtime evidence.
- Add English subtitles to all spoken material.
- Capture the ClickHouse MCP tool call and its user-visible explanation in the same recording.
- Confirm the public repository, hosted application, and demo-video URL work in an incognito browser before submission.
- Rehearse with seeded preferences and approved fixture media so the story remains repeatable.
